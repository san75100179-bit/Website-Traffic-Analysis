🌐 Website Traffic Analysis Dashboard

📌 Project Overview

This project presents an interactive Website Traffic Analysis Dashboard built using Microsoft Power BI. The dashboard helps analyze website performance by tracking key metrics such as users, sessions, engagement, events, and traffic sources. It provides valuable insights to support data-driven business decisions.

🎯 Objectives

Analyze website traffic data.
Identify top-performing traffic sources.
Monitor user engagement metrics.
Track website performance trends.
Build an interactive dashboard for business insights.

📊 Dashboard Features

👥 Total Users
📈 Total Sessions
🎯 Engaged Sessions
📌 Event Count
💯 Engagement Rate
⏱️ Average Engagement Time
🥧 Traffic Source Distribution
📊 Top Traffic Sources
📉 Website Traffic Trend
🎛️ Interactive Filters (Traffic Source & Date)


🛠️ Tools & Technologies

Microsoft Power BI
Microsoft Excel
DAX (Data Analysis Expressions)
Data Visualization

📂 Dataset

The dataset contains website analytics information, including:

Users
Sessions
Engaged Sessions
Engagement Rate
Average Engagement Time
Event Count
Traffic Source
Date & Time


📈 Key Insights

Organic Social generated the highest website traffic.
Direct and Organic Search were major traffic sources.
User engagement varied across different channels.
Website traffic trends were analyzed over time.
Interactive filters allow dynamic analysis based on traffic source and date.
